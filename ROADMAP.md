## Стек (решено 2026-10-26)

Приоритет: надёжность, производительность, долговечность и качество, а не скорость запуска.

- **React + TypeScript (strict)**, сайт на **Next.js 15** (App Router), монорепозиторий на pnpm workspaces. Версии зависимостей закреплены точно.
- `apps/web` — сайт: главная библиотеки, страницы инструментов.
- `packages/ui` — общая оболочка: шапка, инспектор по схеме, контролы, экспорт, сброс, отмена/повтор, токены.
- `packages/<tool>` — движок инструмента без UI (WebGL / Canvas) + модель настроек. Схема инспектора (подписи, вкладки) живёт в приложении.
- Radix (поповеры, списки, диалоги), Zustand + zundo (история), Vitest (тесты движков).
- Хостинг: Vercel или Cloudflare — когда дойдём до публикации.

**В будущем, не сейчас:** аккаунты и сохранение проектов в облаке (например, Supabase). Состояние инструмента уже целиком сериализуется в JSON (`GlobeSettings`) — это и будет «проект».

## Оболочка — решения (2026-10-26)

Ресёрч в `research/ui-shell.md`, макет в `prototypes/mockups/shell-globe.html`.

- Каждый инструмент — отдельный раздел библиотеки, без переключателя. Слева сверху «← Библиотека».
- Шапка: название, «Сохранено», «Сбросить» (с выбором «только стиль / всё» и отменой), отмена/повтор, «Предпросмотр», «Экспорт».
- Справа инспектор со вкладками, под холстом плавающая пилюля действий, тост с «Отменить».
- Выбранная плитка — фиолетовая обводка без смены заливки; выбранный сегмент — серая заливка.
- Только тёмная тема. Акцент фиолетовый (`--t-accent`) — временно, до брендбука. Шрифт Geist везде.
- Адаптив пока не делаем, только десктоп.
